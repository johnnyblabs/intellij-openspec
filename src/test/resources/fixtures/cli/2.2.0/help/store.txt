Usage: openspec store [options] [command]

Create and manage stores - standalone OpenSpec repos you register on this
machine

Options:
  -h, --help                 display help for command

Commands:
  setup [options] [id]       Create and register a local store
  register [options] [path]  Register an existing local store
  unregister [options] <id>  Forget a local store registration without deleting
                             files
  remove [options] <id>      Forget a local store registration and delete its
                             local folder
  list|ls [options]          List locally registered stores
  doctor [options] [id]      Check local store registration and metadata
