Quick Start

  1. Install the plugin — Search for "OpenSpec" in Settings > Plugins > Marketplace, or install from this page. Restart the IDE if prompted.
  2. Open the OpenSpec tool window — Click the OpenSpec icon in the right sidebar, or go to View > Tool Windows > OpenSpec.
  3. Run the Setup Wizard — The wizard launches automatically on first use, or go to OpenSpec > Setup Wizard in the menu bar. It detects your AI tools and configures your preferred delivery method.
  4. Initialize your project — Click "Initialize OpenSpec" in the getting started panel or go to OpenSpec > Init. This creates the openspec/ directory with config, specs, and changes folders.
  5. Propose your first change — Go to OpenSpec > Propose and enter a name for your change (e.g., add-user-auth). Describe what you want to build and why.

Optional: Install the OpenSpec CLI for additional skill generation and advanced workflows. Its standalone installer needs no Node.js:

# macOS and Linux
curl -fsSL https://raw.githubusercontent.com/Fission-AI/OpenSpec/main/scripts/binary/install.sh | sh
# Windows (PowerShell)
irm https://raw.githubusercontent.com/Fission-AI/OpenSpec/main/scripts/binary/install.ps1 | iex

Or use npm install -g @fission-ai/openspec@latest (Node.js 20.19+) or brew install openspec.

How It Works

OpenSpec follows a spec-driven workflow with four phases:

  1. Propose — Define what changes and why. Capture scope and impact before writing code.
  2. Design — Document technical decisions, trade-offs, and architecture.
  3. Implement — Work through a concrete task checklist with AI assistance.
  4. Archive — Completed changes move to the archive. Delta specs merge into your living specifications.

Delivery Modes

Choose how the plugin delivers prompts to your AI tool:

  • Clipboard — Copy prompts and paste into your AI tool's chat (GitHub Copilot, Cursor, Claude Code, or any of the 50 tools OpenSpec supports)
  • Editor Tab — Open prompts in a temporary editor tab for review before pasting
  • Direct API — Generate artifacts directly via Claude, OpenAI, or Gemini APIs with your own API key
